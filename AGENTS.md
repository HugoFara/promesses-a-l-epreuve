# Consignes pour les agents

Lire d'abord `CONTRIBUTING.md` : ses règles (sources, symétrie, historique, présentation) s'appliquent aux agents comme aux humains. En plus :

- **Ne rien publier sans demande explicite.** Un push sur `main` met le site en ligne. Ni commit, ni push, ni ticket, ni document en ligne sans que l'utilisateur le demande.
- **Commits** : conventional commits en français, sans mention d'IA ; ajouter les fichiers par leur nom.
- **Avant de proposer une publication**, lancer `TEST_WEB_STRICT=1 bash scripts/run_all.sh` et vérifier les pages modifiées à l'écran (grand écran et téléphone).
- **Recherche documentaire** : suivre `recherche/CONSIGNES.md` (écrire seulement dans `recherche/<tâche>/`, archiver les sources dans `sources/`, qui n'est pas versionné).
- **Ne jamais faire entrer dans le dépôt** les comptes provisoires de l'association « Des cahiers pour décider et agir ».
- **Connaissances datées** : la période 2026 a beaucoup changé (budgets, lois votées). Ne jamais compléter un chiffre de mémoire.
